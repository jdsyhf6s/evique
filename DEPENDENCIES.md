# External import roots

Existing requirements files are preserved. Some imports below are optional and only loaded by the selected model path.

- PIL
- cv2
- fastembed
- faster_whisper
- numpy
- openai
- tiktoken
- transformers
- ultralytics

Import names can differ from pip package names (cv2/opencv-python, PIL/pillow, yaml/PyYAML). Model weights are provisioned separately.
